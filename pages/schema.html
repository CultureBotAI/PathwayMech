PathwayMech schema

PathwayMech / Schema

One record per pathway: its taxa, participants and reactions as CURIE nodes, and the causal edges between them, each backed by traceable evidence from a reference declared in the same record. This schema states the structure, closed, so an undeclared key is an error. What LinkML cannot state stays in src/pathwaymech/schema.py: that edge endpoints resolve to the record, its taxa, participants or reactions; that consumes/produces edges have participant/reaction endpoints in the proper direction; that qualifiers have unique roles on declared protein/complex participant endpoints; that evidence cites a declared reference; that evidence quotes are human-readable instead of raw provider XML; and that pathway ids are unique across the corpus. An explicit null is an error wherever it appears (the gate generates JSON Schema without nulls): omit an optional key rather than setting it to null.

Generated by just render-pages from src/pathwaymech/schema/pathwaymech.yaml, version 0.1.0. Each class lists the slots LinkML resolves for it. Descriptions are shown as written, without links: the identifiers in them are format examples. Schema licence: BSD-3-Clause. The vendored fleet schemas mech_shared.yaml and history.yaml are published as YAML.
