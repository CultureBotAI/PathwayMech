# Native integration gates

This archive preserves the complete terminal native validate/test/lint/diff-check
run, exact before/after tested-input inventory, runtime settings and pinned
22-artifact vendored check. Every regular archive member is listed in
[source-file-manifest.json](source-file-manifest.json), with original size and
SHA256, and was read back against the source. Hidden and ignored files in the
named output directories were included.

The corpus contains 264 records. All declared maintained inputs were unchanged
through these gates. This cutoff precedes evidence-package/report adoption and
canonical review saving; those later documentation and review additions require
their own checks. Rendering and actual graph/export observations are separately
retained under the root-integration verification package. This archive does not
claim staging, PR, merge or issue closure.
