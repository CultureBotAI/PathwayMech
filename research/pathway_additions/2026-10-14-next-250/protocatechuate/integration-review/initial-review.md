## Finding INT-250-01 — medium — contextual rule also waives pathway-interface labels

The added `MetaCyc` / `reactions` / `GO` contextual-label rule in `conf/identifier_policy.yaml` does not distinguish a molecular activity from a pathway interface in the reactions collection. In an isolated copy, replacing only the `MetaCyc:PWY-2361` interface label with `deliberately wrong pathway interface name` returns no identifier errors. The new rule is described as preserving native reaction descriptions, but also relaxes an independently available canonical pathway name. Evidence: `interface-policy-probe.json`; exact standalone fixture: `policy-interface-fixture/data/pathways/probe.yaml`.

Acceptance criteria: preserve the intended `MetaCyc:5.5.1.2-RXN` contextual reaction description in an exact GO record while rejecting a false `PWY-2361` pathway-interface label. A missing reaction identifier and use of a typed native reaction outside reactions/category molecular_activity must still fail. Keep GO, ChEBI, taxon and protein canonical-label checks enforcing. Prefer an explicit, validated category or typed-identity selector in the contextual rule over a new per-record identifier exception.
