# Independent review of salvage pathway identifier support

The five-file implementation is accepted for integration, with no unresolved actionable code findings. The coordinator reviewed the complete builder diff, both changed test suites, policy and documentation, and the original-source/baseline reproduction helper. The implementation author and this reviewer are separate agents.

PathBank selection uses the exact requested SMP accession plus native unification and URI assertions. It rejects a requested stub, unrelated expanded pathways and ambiguous identities; it preserves native transport and compartment-specific objects. These are identity authorities, not inferred pathway membership or material-transfer assertions. The existing single-pathway archive boundary remains explicit.

NCBI Gene extraction uses the directly requested ID, locus, formal symbol, aliases and taxon. Duplicate/deprecated/redirected identities fail before selection. Expat validates the declaration with parameter-entity loading disabled before ElementTree parses the same buffered bytes. Native external DOCTYPE and omitted status are permitted without synthesizing source assertions; internal subsets and entities are rejected, including encoded originals. The Entrez policy requires canonical labels or native aliases without a contextual exemption.

The independent original-source probe accepted all seven selected original bodies and all 14 new source labels, retaining native aliases. Eight adversarial probes rejected wrong PathBank root requests, mismatched Gene request/body IDs, explicit secondary status in UTF-16, and conflicting native gene taxa before selection in both manifest orders. Probe execution was terminal `3303f3`, exit 0. All five code files and seven source originals were rehashed before and after these probes.
