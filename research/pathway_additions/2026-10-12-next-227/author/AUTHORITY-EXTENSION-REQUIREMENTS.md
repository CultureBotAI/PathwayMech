Preserve the unnamed source-context term policy: do not insert the draft reaction description as a canonical native name.

Required negative probes include an unknown Compound attribute, invalid class value, class on an unsupported placement, wrong side frame/resource/organism, wrong request frame, wrong source version, duplicate selected object and wrong root type. The record must continue using MetaCyc:LYXISOM-RXN with CHEBI:147210; substituting generic RHEA:28059 is not an acceptable implementation fix.
