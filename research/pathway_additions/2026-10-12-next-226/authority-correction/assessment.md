# Typed native reaction provenance correction

Issue [436](https://github.com/CultureBotAI/PathwayMech/issues/436), stable key `ribose-native-reaction-typed-provenance-binding`, is addressed in this external successor candidate, pending independent review and root adoption. No maintained files, Git/GitHub state, shared caches, scientific record, or installed packages were changed.

The new `kind=metacyc-reaction-xml` loader branch requires the exact supported HTTPS `/getxml?id=META:<frame>` request and the same ASCII dotted numeric version grammar as its builder. It binds every typed reaction CURIE to that source's requested frame, including terms that are not currently selected by a record. Alternate hosts, ports, credentials, endpoints, organisms, query forms, fragments, encoded/whitespace aliases, and malformed versions fail. A source cannot establish a second typed identity. Existing type and contextual-policy checks remain in place before contextual bypass. No accession or release is hard-coded. Legacy untyped provenance follows its previous rules.

These are internal snapshot-consistency checks. A syntactically valid version is not attested against XML unavailable to the offline loader; acquisition and builder checks retain responsibility for source bytes, digest, request, and native body/version agreement.
