It supplies no new scientific verdict, code approval, issue closure, gate result or publication acceptance. The integration reviewer authored earlier adapter/retention work and explicitly excluded acceptance of those owners; preserving that review does not alter its independence boundary.

This archive was not one of that review's inspected inputs. The chronology avoids treating later packaging as prior evidence. The separately retained independent authority review and complete-record preparation remain in `../record-and-authority-review-evidence/` and are not duplicated here. Root CI/merge/publication evidence outside these three owners is excluded. The whitespace review is a new successor for the narrow cache XML attribute rule; the earlier authority-source packet and its then-current attribute bytes remain unchanged.

`retention.json` is the portable member/hash index, and `packet-specifications.json` independently pins the expected source manifests, freeze proofs and handoffs. `reports/` contains exact complete report copies selected from archived originals; their correspondence is verified, and they do not substitute for the full archives. All current and initial failed review receipts remain in the complete archives. Original paths mentioned in source text remain historical provenance, not required verifier inputs.

Tar members are sorted regular files with fixed mode, owner and time. Gzip has an empty filename and mtime zero. Parts are consecutive segments of one owner and never mix owners. Nested containers are retained as opaque byte-exact payloads; this package does not claim to inspect their interiors or enlarge the original scientific reading scope. No symlink dependence, network, dependency installation, database cache or unavailable absolute path is required for verification.

With an existing Python 3 runtime, from this directory:

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONNOUSERSITE=1 python3 -B retain.py verify --output .
PYTHONDONTWRITEBYTECODE=1 PYTHONNOUSERSITE=1 python3 -B check_archived_manifests.py .
```

The first command checks expected release scope, every archive/member, complete coverage and readable report copies. The second independently decodes the original source manifests/freezes and compares their entire declared inventory with the portable member index. Both commands are read-only and run without the original scratch owners. Optional `--sources-root ROOT` on the first command also rechecks original frozen owners. A complete deterministic archive/index/report rebuild uses `retain.py build --output FRESH --sources-root ROOT`; existing destinations are rejected. The active verification helpers pass the repository's explicit Ruff configuration with `--no-cache`.

`verification/` retains both portable replay results and the separate original-source recheck. `package-manifest.json` covers every physical retained package file except itself, including hidden/ignored content. The parent independently intakes the package. This author performed mechanical retention only and did not scientifically accept any review's findings.
