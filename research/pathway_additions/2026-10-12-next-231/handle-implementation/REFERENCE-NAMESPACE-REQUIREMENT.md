# Bounded thesis reference requirement

The six-event PPi pathway uses primary inhibitor observations from Taillefer's thesis, issued at `https://mspace.lib.umanitoba.ca/handle/1993/32279`. The persistent identifier is `hdl:1993/32279`. The retained native PDF is `raw/Taillefer-2016-thesis.pdf`, SHA256 `e0276c90358e3f177441ec3f71e99454727a31099a50920a325c7cc31cff8fc8`; the filename follows an earlier citation, whereas the title page says 2017. The repository landing metadata says 2015-04, and the later 2023 paper cites 2016. These dates must remain an explicit source-version conflict.

The primary Chapter 4 Methods/Results, PDF pages 111–121 (printed 86–96), establish preparation-specific PPi substrate inhibition and ATP inhibition in the F6P assay of Cthe_0347. No DOI was found in the retrieved issuing landing's metadata/links. The 2023 paper is a later citation, not the original body for these quantitative inhibitor findings. A fabricated DOI, citation to that later paper as if it contained the original experiment, or omission of the finding would be misleading. The persistent Handle is preferable to using a mutable bitstream UUID as a source identifier. The reference will also carry the issuing HTTPS URL and exact PDF hash.

The accepted EG runtime currently rejects this reference: `src/pathwaymech/schema.py` lines 347–366 call `_validate_curie` for `references[*].id`; lines 655–664 check the global `ALLOWED_CURIE_PREFIXES`, which does not include hdl. Simply adding hdl to that global whitelist would also permit it in biological identifiers, beyond this requirement. The narrow implementation should recognize a bounded Handle syntax in reference IDs only, while retaining rejection in record IDs, taxa, participants, reactions, graph endpoints and ontology/source snapshots. Evidence `reference_id` must still resolve to a declared reference; no free-form citation bypass is requested. LinkML validation must agree with the native validator.

`src/pathwaymech/cli.py` lines 1070–1095 currently has no Handle fallback. The actual renderer at lines 1184–1187 prefers a declared reference URL, so this record does not require a new resolver to render a proper citation link. No resolver change is requested. The source builder's `corpus_ids` excludes references; the ontology builder's recursive `walk_identifiers` does inspect reference IDs but retains only requested ontology prefixes, which exclude hdl. A bibliographic Handle therefore requires no invented canonical biological identity or source-adapter row. Document the accepted Handle grammar as a supported subset, not a universal assertion about every Handle syntax.

Acceptance checks: valid `hdl:1993/32279` reference and evidence link pass both validation paths; existing references are unchanged; malformed empty, whitespace, URL, missing-prefix/suffix Handle forms fail; an undeclared Handle evidence reference fails; Handle record/participant/reaction/taxon IDs remain rejected; page and KGX retain the exact citation and original URL without creating a biological Handle node. Native snapshot loaders must remain closed. Preserve the exact original implementation/runtime bindings and bounded test outputs in a separate implementation package. This document proposes support only; no parser or maintained file has been edited.
